## HilltopAds

The verification file and meta tag use the provided code. `hilltopads_chatgpt_bridge.py` uses the official read-only publisher endpoints for balance, inventory and statistics. Add `HILLTOPADS_API_KEY` as a GitHub Actions secret to enable the sync. The site intentionally embeds no betting, casino, gambling, popunder or direct-link advertising code.

HilltopAds publisher API documentation states that publisher API operations are GET/read-only. It does not provide campaign creation or editing through this bridge.
